---
description: Session startup - load context and identify focus
---

Think OS session startup. Execute the following:

1. **Read core context** (in this order):
   - `memory/me.md` — Who is this person
   - `now.md` — Active topics
   - `memory/timeline/perspective.md` — Where are we in the timeline
   - `memory/timeline/todo.md` — Pending tasks

2. **Check recent activity**:
   - Read `memory/timeline/daily/` for the most recent daily index
   - Note any open threads from previous session

3. **Identify current context**:
   - What phase/stage are they in based on `perspective.md`?
   - What goals/deadlines are coming up?
   - What's the current priority?

4. **Output a brief summary**:
   - **Current focus**: [From now.md and perspective.md]
   - **Recent progress**: [From latest daily index]
   - **Today's suggested priorities**: [Based on todos and deadlines]
   - **Open threads**: [From previous session]

5. **Ask**: "What would you like to work on today?"
