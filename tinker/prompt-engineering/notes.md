# Prompt Engineering

> Learning how to communicate effectively with LLMs.

---

## Why I'm exploring this

Building the AI writing tool made me realize: the prompt is everything. Same model, different prompt = completely different results. Feels like learning a new language.

---

## Key learnings so far

### 2026-01-10: The basics

**Structure matters.** Breaking prompts into clear sections helps:
```
ROLE: You are a writing assistant...
CONTEXT: The user is writing a blog post about...
TASK: Help them...
CONSTRAINTS: Keep it under 200 words...
```

**Examples are powerful.** Showing the model what you want (few-shot) works better than describing it.

### 2026-01-14: Iteration insight

Had an aha moment: prompting is like design. You don't get it right the first time. You:
1. Try something
2. See what's wrong
3. Adjust
4. Repeat

The prompt is a prototype. Ship it, see what breaks, fix it.
